Hethereau Ledger - sample recorder
==================================

What it does: saves the network packets of the running Neverness to Everness
client (only the game's own connections) so the pull history decoder can be
built. It only reads traffic. It does not change the game or its files.

1. Extract this zip to a folder (do not run it from inside the zip).
2. Start the game and log in.
3. Double-click hl-record.cmd and press Yes when Windows asks for admin rights.
   If SmartScreen says "Windows protected your PC": More info -> Run anyway.
   If Windows Firewall asks about PowerShell: Allow.
4. Follow the steps in the window: press L/S/A/M before opening each history,
   scroll each one to the end, then press Q.
5. A zip appears on your Desktop: hethereau-sample-....zip. Send it to Claude.
